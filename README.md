## 🌟 What's New in v2.0

* ⚡ **CHAMA MOD Framework Powered:** Upgraded from legacy forks to [`chama-mod-framework`](https://github.com/chamanemax02/chama-mod-framework) based on Baileys v7.0.0-rc14.
* 🎮 **12+ Interactive HTML5 / Canvas Games Suite:** Play real HTML5/Canvas games directly inside WhatsApp chat:
  - 🏎️ **`.rush`** - Highway Rush 4-lane high-speed traffic racing
  - 🐥 **`.flappy`** - Flappy Cyber bird through neon cyber pillars
  - 🐍 **`.snake`** - Neon Snake 3000 with glowing food & D-pad
  - 🧱 **`.bricks`** - Neon Brick Breaker / Arkanoid paddle
  - 🚀 **`.space`** - Galaxy Strike alien fleet retro shooter
  - 🏓 **`.pong`** - Cyber Pong 1v1 vs Smart AI opponent
  - 🎯 **`.knife`** - Knife Master rotating target wheel thrower
  - 🧩 **`.2048`** - Neon 2048 slide & merge puzzle
  - 🏃 **`.runner`** - Cyber Runner endless 2D parkour
  - 🍉 **`.fruit`** - Fruit Slicer ninja swipe game
  - 🧠 **`.memory`** - Memory Matrix Simon-Says pattern recall
  - 🏹 **`.tower`** - Castle Defender arrow turret defense
  - 🕹️ **`.games`** - All-in-One Games Hub Menu
* 📹 **Real-Time VoIP Video Call Streaming Engine:** Broadcast MP4 video files into real WhatsApp video calls at 30 FPS using FFmpeg transcoding and VP8 RTP packetizer (`.callvideo` / `.videocall`).
* 📞 **Native WhatsApp Call Links:** Instantly generate official WhatsApp Voice and Video call room links (`.voicelink` / `.videolink`).
* 🎥 **Video Notes (PTV):** Convert any attached or quoted video into WhatsApp live round video bubble note (`.ptv` / `.videonote`).
* 🎠 **Native Flow & Carousel Cards:** Rich interactive buttons (`quick_reply`, `cta_url`, `cta_copy`, `single_select`) and horizontal scrollable carousel cards (`.chamamenu`, `.carousel`, `.rich`).
* 🛡️ **Anti-Ban & Anti-Spam Protection:** Multi-browser spoofing, random jitter delays, seen status duplicate filters, nocturnal DND sleepy mode, and 1-hour spam rate-limiting.

## 🚀 Quick Setup & Run

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/chamanemax02/chama-shield.git
cd chama-shield
npm install
```

### 2. Start Bot & Web Control Center
```bash
npm start
```
* Dashboard URL: `http://localhost:8080`
* Enter your phone number with country code (e.g. `94783314361`) to pair your WhatsApp session!

---

## ☁️ Deployment (Railway / Render / VPS)

* Set `MONGO_URI` to your MongoDB cluster connection string.
* Set `PORT` (default `8080`).
